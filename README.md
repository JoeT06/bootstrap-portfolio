# Joe Torres · Bootstrap portfolio site

Static Bootstrap 5.3 version of my IT operations portfolio, hosted on AWS Amplify.

- `index.html` is at the repo root, so Amplify's default build settings serve it as is.
- Bootstrap is a local copy: `css/bootstrap.min.css` and `js/bootstrap.bundle.min.js`.
- `css/site.css` holds the dark terminal theme on top of Bootstrap.
- `img/network-diagram.png` is a generalized diagram of the environment I support.

Work details are generalized. No company names, people, addresses, or internal configuration.

Full write-ups and scripts: [JoeT06/it-ops-portfolio](https://github.com/JoeT06/it-ops-portfolio)
