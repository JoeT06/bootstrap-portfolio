Rolling out owner

Production dashboard kiosks

Six TVs on the production floor show OEE dashboards from Intel NUCs. Without automation, a reboot, an expired session, or a pop-up leaves a TV stuck until someone walks over. Four PowerShell scripts now handle auto-login, sign-in to the OEE app over the Chrome DevTools Protocol, scheduled refresh, and relaunching Edge when it hangs.

PowerShellEdge kiosk modeDevTools ProtocolDPAPISysinternals Autologon 
while ($true) {
  Start-Sleep 60
  # STOP file = maintenance mode
  if (Test-Path $StopFile) { exit 0 }
  # Edge hung or closed: relaunch it
  if (-not (Test-Browser)) {
    Start-Display; continue
  }
  # app refresh first, page reload as fallback
  if ($minutesSinceRefresh -ge $RefreshMinutes) {
    Invoke-Refresh
  }
  # signed out or off the dashboard: fix it
  if (Ensure-LoggedIn) { Ensure-Dashboard }
}
